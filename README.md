# AMAR YT V5

ملفّا التحكم على فرع `main` هما `config.json` و`mods.json`. يقرأهما التطبيق عبر HTTPS دون مفتاح. عند انقطاع الاتصال يستخدم آخر إعداد صالح، وفي أول تشغيل يستخدم النسخة المحلية. يُجلب فهرس المودات عند فتحه. يعرض المشغّل الترحيب والإشعار بعد ظهوره.

| المطلوب | التعديل |
|---|---|
| ترحيب | ضمن `welcome` غيّر `enabled` و`title` و`body` و`action`. استخدم `frequency: "once"` لمرة واحدة أو `"launch"` لكل تشغيل. غيّر `id` لنشر رسالة جديدة. |
| إشعار أو أخبار | ضمن `notification` استخدم نفس حقول الترحيب ومعرّفًا جديدًا. تظهر أسطر `news` ضمن «معلومات النسخة والتواصل». |
| تحديث اختياري | فعّل `update.enabled` واجعل `latest` أعلى من النسخة المثبتة، و`minimum` مساويًا لها أو أقل. اضبط الرابط والنص والمميزات في `url` و`action` و`features`. رقم V5 الداخلي هو 5. |
| تحديث إجباري | اجعل `minimum` أعلى من 5 و`latest` مساويًا له أو أعلى. ضع في `expiresUTC` موعدًا مستقبليًا ينتهي بـ Z خلال الأيام السبعة القادمة بصيغة سنة-شهر-يوم ثم T والوقت. تحقق من رابط التحديث قبل تفعيل `enabled`. |
| إلغاء الإلزام أو استرداد نسخة | اضبط `update.enabled` على `false`. يتحقق التطبيق عند الفتح وعند الرجوع من رابط التحديث أثناء الإلزام. ينتهي الحظر المحفوظ عند موعد الانتهاء حتى بلا اتصال. الموعد الفارغ يسمح فقط بالتنبيه الاختياري. |
| الهوية والصور | ارفع الصور إلى `images/` ثم ضع روابط HTTPS المباشرة في `image` أو `identity.logo`. غيّر `identity.name` و`identity.accent` للواجهة الإضافية. ألوان HEX من ست خانات. |
| الحسابات والأزرار | غيّر عناوين `social` لقسم معلومات النسخة. زر التواصل داخل الرسالة مستقل وتحدده `contact` و`contactURL`. صور وحسابات شاشة V4 الأصلية محفوظة محليًا. |
| المتجر | `sections.mods` يتحكم بزر القائمة الجانبية. يُحجز صف للمودات تحت الهوية، ويظهر رمز الصندوق عند طي الشريط. |

## معرض السيارات العراقية والخليجية (51 مصدرًا)

[**شاهد 51 سيارة بالاسم العربي والصور وروابط الصفحات الأصلية**](research/IRAQI-GULF-50-PHOTOS-AND-SOURCES.md) · [فهرس JSON الموثق](research/iraq-gulf-verified-source-gallery.json).

هذا معرض مصادر **غير قابل للتثبيت تلقائيًا**؛ لا تضع رابط زر تحميل GTA5-Mods في `archiveURL` إلا إذا أثبت الفحص أنه رابط مباشر لملف ZIP وله حجم وبصمة SHA-256 صحيحة، وتأكدت من حقوق إعادة النشر ومن أن الاستيراد يعمل على الآيباد. المود الوحيد الحالي المثبت والمختبر هو Iraqi Garage؛ ولم تتغير قائمة `mods.json` بمرشحات غير مختبرة.

## مودات السيارات — بنية ZIP التي ثبت نجاحها

تجربة iPad أثبتت نجاح حزمة `Iraqi Garage` في التنزيل والاستيراد إلى القائمة الأصلية. مودات المتجر موجودة في `mods.json` على GitHub وليس داخل IPA. حاليًا الحزمة الوحيدة المنشورة هي سايبة `sj131` وبيجو `405glxfnt` وتشارجر `srtday20`.

**للإضافات المستقبلية:** فضّل حزمة DLC تحتوي على `update/x64/dlcpacks/<vehicle>/dlc.rpf` وليس ZIP من ملفات `stream/*.yft` منفردة. افحصها باستخدام `python3 scripts/inspect_dlc_zip.py /path/to/car.zip` ثم اختبرها داخل اللعبة. نجاح فحص البنية لا يضمن استيرادها أو تشغيلها. راجع [دليل البنية الناجحة](docs/DLC-ZIP-COMPATIBILITY-AR.md) و[الحزمة المعتمدة](docs/IRAQI-GARAGE-PUBLISH-AR.md).

بعد اختبار المود ورفع ملف ZIP الحقيقي إلى GitHub Releases، أضف إلى `mods.json` رابط HTTPS في `archiveURL`، الحجم بالبايت في `archiveSize`، بصمة SHA-256 في `archiveSha256`، بيانات الصورة واسم المود ومعرّفه، ومجلدات `expectedMods` المؤكدة. بقاء تنزيل الملفات المفردة دعمًا تقنيًا قديمًا لا يعني أنها متوافقة مع مستورد DLC؛ لا تنشرها على أنها حزم سيارات قابلة للتثبيت دون اختبار. لا تغير زر PLAY أو محرك اللعبة لاستقبال مود جديد.


## الإدارة والتشخيص — البناء 8

يحمّل الملف التنفيذي المكتبة مباشرةً كتَبَعية مطلوبة في البناء 8. يجب أن تشمل إعادة التوقيع Frameworks/AMARYTKit.dylib؛ تعذّر تحميل تبعية مطلوبة قد يمنع بدء التطبيق.

اسم التطبيق GTA V ومعرّفه com.macport.gtav. الرسالة المحلية مفعلة لكل تشغيل بمعرّف welcome-build8-local، وتستبدل النسخة المتصلة محتواها بآخر ملف إعداد صالح. يظهر الترحيب والإشعار والتحديث في بطاقة UIKit، وتبقى واجهة الفهرس داخل المشغّل. اسم مجلد كل مود يساوي معرّفه.

البناء التشخيصي يعرض شارة AMAR YT Kit Active · Build 8 داخل المشغّل عند الارتباط بمثيله الظاهر. لا تعتمد الشارة على GitHub أو على نجاح تحميل ملف السياسة. لإجراء تجربة نظيفة وقّع التطبيق بشهادتك المعتادة مع الحفاظ على المعرّف، وافتحه أول مرة دون إنترنت. أغلق الترحيب، اختبر PLAY، ثم افتح الشريط الجانبي وجرّب المودات. اتصل بالإنترنت وأعد فتح المشغّل أو اضغط فحص التحديث. غيّر welcome.id وwelcome.title وانشر config.json لاختبار المحتوى المتجدد. لا تحذف بيانات اللعبة لإعادة الاختبار.

يمكن قراءة Documents/AMARYT-debug.txt، أو توصيل الآيباد بالماك وفتح Console واختيار الجهاز ثم بدء البث قبل فتح اللعبة. ابحث عن AMARYTKit. إذا اختفت الشارة ولم يظهر سجل المكتبة، أعد البحث عن GTA5 وdyld وLibrary Validation أثناء نفس المحاولة. ابحث عن startKit entered ثم launcher viewDidLoad أو probe mounted ثم badge attached ثم native welcome mounted. عدم وجود ملف داخل تطبيق الملفات بمفرده غير حاسم.

## إعادة بناء حزمة الاختبار

يقبل السكربت حصراً IPA المطابق لبصمة البناء 7 المثبتة في scripts/rebuild.py. تحتاج إلى zsign، وXcode على الماك أو Zig 0.13 وiPhoneOS SDK على لينكس. يمكنك ضبط ZSIGN على مسار zsign المطلق، وLD64 لمسار ld64.lld، وZIG وIOS_SDK عند البناء على لينكس. يعيد السكربت توقيع الحزمة والمكتبات توقيعاً تحضيرياً. التثبيت على جهاز عادي يتطلب توقيعاً بملف تعريف وشهادة صالحين للجهاز.

```sh
node scripts/test.js
python3 scripts/rebuild.py GTA-V-AMARYT-Build7.ipa GTA-V-AMARYT-Build8.ipa
```
