# خطة إدخال مودات السيارات والأزياء العراقية والخليجية — AMAR YT

## الحالة الحالية بتاريخ 22 نوفمبر 2026

- **المود الوحيد المنشور في المتجر** هو Iraqi Garage (سايبة + بيجو 405 + تشارجر). المستخدم أكد أنه نُزّل واستُورد من داخل Build 9 وظهر في قائمة المودات الأصلية.
- أضفنا **فهرس بحث منفصل** فيه 14 مصدرًا مرشحًا بأسماء عربية وصور أصلية حيث أمكن: [research/iraq-gulf-mod-candidates-ar.json](../research/iraq-gulf-mod-candidates-ar.json).
- هذه المرشحات **ليست ملفات مود مثبتة**: لا توجد لدينا بعد نسخ ZIP موثقة الحفظ والبصمة وحق إعادة التوزيع لهذه الصفحات. لذلك لم نضفها إلى `mods.json`، تجنبًا لكسر التجربة الناجحة.
- بقيت طلبات شيري تيغو، شيري QQ، ستاركس، فتون، «بينقل»، الدشداشة والعقال والزي الكردي المدني بحاجة لمصدر مطابق أو تحديد موديل، ولم نخترع رابط ZIP لها.
- صور المعاينة الموثقة هي روابط لموقع المطور الأصلي، وليست صورًا أعيد رفعها إلى GitHub أو ادعاء إذن إعادة استخدامها.
- المستخدم يريد اللغة العربية **في متجر AMAR YT وفي قائمة المودات الأصلية**. `mods.json.name` يغير اسم بطاقة **المتجر** فقط؛ لا يغير الاسم الداخلي `sj131` / `hilux21` الذي يعرضه المستورد الأصلي في القائمة اليمنى. لضمان ظهوره بالعربية هناك يجب تطوير طبقة عرض في IPA، وليس إعادة تسمية ملفات DLC أو المعرّفات التي يعتمدها المحرك.

## سياسة قبول ملف ZIP جديد

1. رابط صفحة المؤلف الأصلي وصور المود نفسه، مع مراجعة حقوق إعادة الاستخدام والنشر. **لا ترفع مودات الآخرين على GitHub Releases دون تصريح أو ترخيص يسمح بذلك.** يمكن حفظ روابط صفحاتهم للبحث دون نسخ الملفات.
2. الحصول على أرشيف ZIP الأصلي كاملًا، ثم تشغيل `python3 scripts/inspect_dlc_zip.py SOURCE.zip`.
3. إذا كانت الملفات `dlc.rpf` حقيقية لكن تحت مسار مختلف مثل `AddOn/hilux21/dlc.rpf`، يمكن إنتاج نسخة اختبار محلية ذات بنية `update/x64/dlcpacks/hilux21/dlc.rpf` باستخدام:

   ```bash
   python3 scripts/normalize_addon_zip.py SOURCE.zip TEST-hilux21.zip
   python3 scripts/inspect_dlc_zip.py TEST-hilux21.zip
   ```

   الأداة **لا تصنع** مودًا من `stream/*.yft` أو `*.meta`، ولا تثبت دعم المنفذ. لا توزع نسخة مشتقة دون إذن صاحب حقوق الملف.
4. اختبار استيراد ZIP يدويًا داخل GTA V على الآيباد. بعدها تجربة الاستيراد التلقائي من AMAR YT في بيئة الاختبار؛ ثم التأكد من ظهور المود بالاسم الداخلي في قائمة المودات والتوليد الفعلي داخل اللعبة، دون التأثير على PLAY.
5. عندما تسمح الرخصة أو صاحب المود بإعادة التوزيع، ارفع ZIP المتحقق منه إلى GitHub Releases وسجّل الاسم العربي والصورة المصرح بها والـ `archiveURL` والـ `archiveSize` والـ `archiveSha256` الحقيقية في `mods.json`. لا تتلاعب بـ `expectedMods` لكي يعرض نجاحًا غير حقيقي.
6. تتطلب مودات الملابس/الشخصيات فحصًا مختلفًا؛ مودات `EUP/Replace` لا تعتبر تلقائيًا `dlcpacks/dlc.rpf` لسيارة. يجب فحص آلية المستورد الأصلية للنوع المحدد قبل النشر.

## معيار الأسماء العربية في المتجر

- `name`: الاسم الذي يراه المستخدم؛ مثال «تويوتا هايلوكس GLX 2021».
- `id`: معرف ASCII ثابت وفريد؛ مثال `hilux21`.
- `expectedMods`: أسماء مجلدات Add-On التي ثبت أن المستورد ينشئها؛ مثال `["hilux21"]`.
- `image`: صورة **نفس المود** من مصدر مرخص، وليست صورة موديل مشابه.
- لا تكتب «تم التثبيت» إلا بعد تأكيد مستورد اللعبة ووجود الملفات؛ فحص Zip/CRC/RPF7 مجرد فحص بنيوي.
